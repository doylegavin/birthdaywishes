# Birthday Website for Vivienne 🎉

A beautiful multilingual birthday website featuring:
- Multilingual birthday messages (English, Spanish, Polish, Mandarin)
- Animated confetti background
- Responsive design with pink theme

## Features

- **Multilingual Support**: Switch between 4 languages
- **Confetti Animation**: Beautiful falling confetti particles
- **Responsive Design**: Works on desktop and mobile
- **Modern UI**: Clean, centered design with hover effects

## Setup & Development

### Prerequisites
- Node.js installed on your system

### Installation
```bash
npm install
```

### Development
```bash
npm start    # Start development server on port 3000
npm run dev  # Same as start with file watching
npm run serve # Start server on port 8080
```

### Project Structure
```
├── index.html          # Main HTML file
├── styles.css          # Main stylesheet
├── js/
│   ├── main.js         # Language switching functionality
│   └── confetti.js     # Confetti animation
├── package.json        # Project configuration
└── README.md          # This file
```
